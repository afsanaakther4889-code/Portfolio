# 尖叫工业设计教育 · 作品展示官网

工业设计考研复试作品集的**作品展示**站点。参考 Squarespace 的板块架构与编辑排版语言；
主色调为 **白 / 灰 / 黑 / 荧光绿**，前段深色、后段黑白交替。

纯静态：**双击 `index.html` 即可查看**，不需要构建、不需要服务器。
（站点用了三个 React Bits 组件的原生移植：DriftWall / Masonry / TearTicket，均无 React 依赖。）

> 全站没有课程、班期、报名、招生内容，只做作品展示。

## 1. 开场：黑屏粒子 → 撕票入场

进入页面先看到一块干净的黑色屏幕，缓慢漂移的粒子在背景里连成细线；
约 0.6 秒后，一张**浅白灰纸质的作品集观展券**在画面正中升起。

- **撕开**：按住票据右侧存根向右拖 ≈70px，纸纤维被拉断、桥丝回缩、存根脱落，
  之后遮罩淡出、锁定解除，才开始浏览网页内容。
- **引导**：一张白色手掌图标从撕口线开始向右滑动约 115px，4.6 秒一轮，
  中段开始淡出——用动效说明「从右往左撕」这个动作；一按下拖动就立刻隐藏。
- **跳过**：票下方的「跳过 · 直接进入」按钮，或按 `Esc`。
- **键盘**：Tab 到存根，`Enter` / `Space` 直接撕开。
- 票面：`ADMIT ONE`、`作品集观展券`、`NO. 000026`、竖排「撕开入场 / TEAR TO ENTER」。
- 纸感由三层叠出来：细颗粒纤维（186px）+ 大块云斑（520px, `multiply`）+ 边缘压暗；
  纸上还压了一行微印刷小字和一个被裁切的 `PORTFOLIO` 大字底纹。

实现：

| 文件 | 作用 |
| --- | --- |
| `assets/js/tear-ticket.js` | TearTicket 原生移植：撕口几何、桥丝拉伸/回缩、拖拽角度、掉落物理、3D 倾斜 |
| `assets/css/tear-ticket.css` | 票面样式（clip-path 撕口、纸纹、存根） |
| `site.js` 第 6.1 节 | 遮罩开关、粒子画布、票据参数、手指提示 |

票据尺寸 **680×360**（存根 215），在 `.ticket` 里定义：

```css
.ticket { width: min(680px, calc(100vw - 48px)); }
```

## 4. 三个移植的组件

### DriftWall（首屏背景）

3D 漂移作品墙，5 列（平板 4 / 手机 3），鼠标视差 + 悬停抬升 + 点击进大图，离屏自动暂停。

### Masonry（作品集单页）

- 95 张按真实宽高排布（`data.js` 里的 `more.dims`），自动列宽 240px，每 9 页一张双列宽图。
- 滚动进入时从下方弹入（弹簧 + 位移 + 模糊转清晰），悬停放大，点击打开自带灯箱。
- 开了 `parallax: 0.05`：滚动时每列有极轻微的纵向错位，画面更有纵深。
- 悬停字幕显示**所属项目名**（`data.js` 的 `more.titles`），而不是页码。

### TearTicket（开场票据）

见第 1 节。

## 5. 票据化的视觉细节

- **撕口线**：作品卡与调研卡在图片与标题之间有虚线 + 两端缺口（`::before/::after`
  用区块底色画圆），像票根撕口。
- **卡片悬停**：封面会交叉淡入到同一项目的另一页（`.work__img--alt`），
  一次悬停看到两个画面；同时有极慢的 1.06 → 1.02 缩放。
- **编号**：作品编号显示为 `NO.01`。
- **等宽字**：编号、`PAGE 041`、按钮辅助文字都用等宽字体 + 字距。

## 6. 配色

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#ffffff` | 浅色区块 |
| `--paper-warm` | `#f2f2f0` | 作品 / 单页 / 反馈区 |
| `--dark` | `#070709` | 深色区块 |
| `--ink` | `#0b0b0c` | 文字、浅色区按钮 |
| `--line` / `--line-strong` | `#e4e4e0` / `#cbcbc6` | 浅色区分隔线 |
| `--accent` | `#c6ff00` | 荧光绿，只做点缀 |

深色区块统一用 `.sec--dark`：只翻转文字与分隔线变量，不翻转 `--ink`。
荧光绿在浅色底上不做文字色，只做块与线；深色底上才是自由色。

## 9. 换图 / 加项目

1. 图片按 `full-01.webp / thumb-01.webp / mini-01.webp` 命名，放进 `assets/img/w/<代号>/`。
2. `data.js` 加一项（`no / title / en / cat / count / base / accent / desc / spec`）。
3. `index.html` 作品区复制一个 `<article class="work">`，改 `data-work` 与 `data-cats`。
4. 单页：图片放 `assets/img/pages/`，改 `data.js` 里 `more.count` 与 `more.dims`；
   `more` 带 `wall: false`，不会进入首屏漂移墙和作品墙。
